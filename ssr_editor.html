SSR Editor (Huidu receive-card .ssr)

Kéo-thả file .ssr vào đây hoặc bấm "Mở file". Chạy hoàn toàn offline, không gửi dữ liệu đi đâu.

Mọi thẻ <X Value="..."/> (trừ <Raw>). Sửa dưới dạng văn bản thô. Huy hiệu xanh = cũng vá byte trong gói Raw; vàng = chỉ sửa XML. Lọc:

Tên (Field)Giá trị (Value)Raw?

Gói:

Offset tính từ đầu payload (byte 17 của gói). xanh = offset đã xác nhận, vàng = offset đoán (không vá), đỏ = byte khác bản gốc. Di chuột để xem tên trường.
