What is Led Shows?

One tool from bare LED module to running show

Led Shows by Caronon Team is a professional Windows application for designing irregular and large-format LED screens driven by led controller cards. It handles the whole chain: describing each LED module, arranging modules into any shape, wiring data paths, creating content, simulating the final output and generating the card files.

Led Shows Web takes the same core features to the browser. It runs on any OS and tablet, keeps projects in the cloud, supports team sharing, and keeps compatibility with existing .Map, .Proj and .pcfg files.

Desktop today

  • Windows only (WinForms + OpenGL)
  • Local installation & license
  • Files shared manually

Web tomorrow

FAQ

Questions

Will my existing desktop projects open in the web version?

Yes. The web version uses the same core library for .pcfg, .Map and .Proj, so existing files open as-is.

Which browsers are supported?

Recent versions of Chrome, Edge, Firefox and Safari support editing and simulation.

Does it work offline?

The web app is planned as an installable PWA. Once installed, mapping, simulation and export work offline; cloud sync resumes when you reconnect.

Will the desktop app still be maintained?

Yes. Both apps share the same core, so fixes and new chip drivers reach desktop and web at the same time.

Is my content uploaded to the cloud?

Only if you choose cloud storage. Simulation and export run locally in your browser on your own GPU.
